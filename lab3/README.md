# Homestay Teloi Kanan, Kuala Ketil, Kedah

Laman web rasmi Homestay Teloi Kanan yang lengkap dengan:
1. Bahagian borang tempahan (Booking): Tarikh Masuk, Tarikh Keluar, Bilangan Pax (12 - 16 Pax), butang "Book Now!" dan "Tanya WhatsApp".
2. Bahagian footer hijau gelap berlatarbelakangkan maklumat lengkap Homestay Teloi Kanan, Alamat Rasmi (Kg Kuala Cahaya Teloi Kanan), Pautan Laman, Waktu Check-in/Check-out, dan butang floating WhatsApp (+6011243598).
3. 4 keping gambar asal penginapan di folder `assets/images/`.

Cuma ekstrak (unzip) fail ini dan klik `index.html` untuk terus melihat laman web.
